# Implementation Plan: Video Chat Room

- [ ] **1. Инициализация монорепозитория и базовая настройка**
  - Создать структуру папок `client/` и `server/`, настроить `package.json`, TypeScript, Vite (frontend) и Express + Socket.io (backend).
  - _Requirements: FR-1, Design: Раздел 2_

- [ ] **2. Backend: Реализация модуля управления комнатами (RoomManager)**
  - 2.1 Написать `RoomManager` с методами создания комнат, добавления/удаления участников и проверки лимита <= 4.
  - 2.2 Добавить хранение истории сообщений чата в памяти комнаты.
  - _Requirements: FR-1, FR-2, NFR-2, Design: Раздел 3_

- [ ] **3. Backend: Socket.io Сигналинг и Чат Handlers**
  - 3.1 Реализовать обработку событий входа/выхода из комнаты (`room:join`, `room:leave`) и отправку отказа `room:full`.
  - 3.2 Реализовать проброс WebRTC сигналинга (`webrtc:offer`, `webrtc:answer`, `webrtc:ice-candidate`).
  - 3.3 Реализовать обработку и рассылку чат-сообщений (`chat:message`) и статусов медиа (`media:toggle`).
  - _Requirements: FR-1, FR-3, FR-4, FR-5, Design: Раздел 4_

- [ ] **4. Frontend: Экран входа и валидация имени (JoinScreen)**
  - Написать форму ввода имени пользователя с валидацией (до 30 символов, очистка от пробелов) и кнопками «Создать» / «Присоединиться».
  - _Requirements: FR-1, FR-6, Design: Раздел 2_

- [ ] **5. Frontend: Менеджер медиа-потоков (useMediaStream Hook)**
  - Написать кастомный хук для захвата видео и аудио через `navigator.mediaDevices.getUserMedia` с корректной обработкой отказа в правах или отсутствия камеры.
  - _Requirements: FR-3, NFR-3, Design: Раздел 1_

- [ ] **6. Frontend: WebRTC Mesh & Socket Hook (useWebRTC Hook)**
  - 6.1 Написать хук подключения к Socket.io и менеджер P2P-соединений `RTCPeerConnection` для каждого нового участника.
  - 6.2 Реализовать обработку Offer/Answer/ICE candidate и добавить публичные STUN-серверы Google.
  - _Requirements: FR-3, NFR-1, Design: Раздел 1, Раздел 4_

- [ ] **7. Frontend: Сетка видео и отдельная плитка участника (VideoGrid & VideoTile)**
  - 7.1 Написать адаптивный UI сетки (`VideoGrid`), автоматически переключающий CSS-сетку в зависимости от количества участников (1x1, 1x2, 2x2).
  - 7.2 Написать `VideoTile` с отображением видеопотока, аватарки-заглушки при выключенном видео, оверлея с именем и плашки статуса микрофона.
  - _Requirements: FR-2, FR-3, NFR-3, Design: Раздел 2_

- [ ] **8. Frontend: Панель управления звонком (ControlBar)**
  - Реализовать кнопки включения/выключения микрофона и камеры, кнопку копирования ссылки на комнату и кнопку «Покинуть комнату».
  - _Requirements: FR-3, FR-4, FR-5, Design: Раздел 2_

- [ ] **9. Frontend: Текстовый чат и боковая панель (ChatPanel)**
  - Написать интерфейс чата с выводом текстовых и системных сообщений, списком участников, вводом текста и автоскроллом к последнему сообщению.
  - _Requirements: FR-4, FR-5, Design: Раздел 2_

- [ ] **10. Тестирование, полировка UI и обработка краевых случаев**
  - 10.1 Провести интеграционное тестирование: обработка 5-го пользователя (`room:full`), корректное очищение ресурсов при закрытии вкладки.
  - 10.2 Настроить обработку ошибок сети и браузерных Autoplay-ограничений для видео/аудио элементов.
  - _Requirements: NFR-1, NFR-2, NFR-3, Design: Раздел 1_
