# Product Requirements Document (PRD): Video Chat Room

| Metadata             | Value                                                        |
| -------------------- | ------------------------------------------------------------ |
| **Feature Name**     | `video-chat-room`                                            |
| **Document Version** | 1.0.0                                                        |
| **Target Audience**  | Пользователи, которым нужен быстрый видеочат без регистрации |

---

## 1. Обзор продукта

Приложение представляет собой веб-сервис для создания временных видеокомнат с возможностью текстового чата. Главные особенности: отсутствие авторизации, генерация уникальной ссылки на комнату и ограничение до 4 участников на комнату.

---

## 2. Функциональные требования (Functional Requirements)

- **FR-1: Создание и вход в комнату.** Пользователь может ввести имя и создать новую комнату или присоединиться по имеющемуся ID/ссылке.
- **FR-2: Лимит участников.** В одной комнате может находиться не более 4 участников одновременно. При попытке входа 5-го пользователя возвращается ошибка `room:full`.
- **FR-3: Видео и аудио связь (WebRTC).** Автоматическое установление P2P-соединения между всеми участниками (Mesh-топология) для передачи потоков видео и звука.
- **FR-4: Управление медиа-потоками.** Возможность включать/выключать свою камеру и микрофон через интерфейс (ControlBar).
- **FR-5: Текстовый чат.** Общий текстовый чат комнаты с поддержкой системных сообщений (вход/выход пользователей).
- **FR-6: Валидация данных.** Имя пользователя ограничено 30 символами и очищается от лишних пробелов.

---

## 3. Нефункциональные требования (Non-Functional Requirements)

- **NFR-1: Производительность.** Минимальная задержка сигналинга (< 50мс) и низкие задержки медиапотока через P2P.
- **NFR-2: Хранение данных.** Все данные комнат и сообщений хранятся исключительно в оперативной памяти (In-Memory) и удаляются при закрытии комнаты.
- **NFR-3: UX / Адаптивность.** Сетка видео автоматически перестраивается под количество участников (1x1, 1x2, 2x2).
