# 📹 WebRTC Multi-User Video Chat & Text Chat

Полнофункциональное веб-приложение для групповых видеозвонков и текстового чата в реальном времени. Реализовано на архитектуре **Full-Mesh WebRTC** с использованием **Socket.io** в качестве сигнального сервера.

---

## 🚀 Основной функционал

- **Видеоконференции (до 4 участников):** Полносвязная (Full-Mesh) P2P-сеть с обменом медиапотоками без применения SFU/MCU медиасерверов.
- **Текстовый чат:** Обмен сообщениями в реальном времени в рамках комнаты с сохранением истории сообщений во время текущей сессии.
- **Управление медиаустройствами:** Возможность налету включать/отключать камеру и микрофон с трансляцией статуса другим участникам.
- **Системные уведомления:** Оповещения о входе/выходе участников, переполнении комнаты и ошибках доступа к устройствам.
- **Динамический UI Grid:** Адаптивная сетка видеокарточек, масштабирующаяся под количество участников.

---

## 🛠 Технологический стек

### Client

- **React 18** + **TypeScript**
- **Vite** — сборщик проекта
- **Tailwind CSS** + **Lucide React** — стилизация и иконки
- **Socket.io-client** — WebSocket-соединение с сигнальным сервером
- **WebRTC API** — установка P2P-соединений (`RTCPeerConnection`, `getUserMedia`)

### Server

- **Node.js** + **Express**
- **TypeScript**
- **Socket.io** — обработка сигналов (Signaling), ICE-кандидатов и комнат

## ⚡ Быстрый запуск

### Предварительные требования

Убедитесь, что у вас установлены **Node.js** (версии 18 или выше) и **npm**.

### 1. Установка зависимостей

В корневой директории проекта выполните команду, которая автоматически установит зависимости для корня, клиента и сервера:

```bash
npm install

```

### 2. Запуск в режиме разработки

Для одновременного запуска клиента и сервера выполните:

```bash
npm run dev

```

- **Клиент** автоматически откроется в браузере по адресу: `http://localhost:5173`
- **Сигнальный сервер** заведётся на порту: `http://localhost:3001`

---

## 🧪 Инструкция по тестированию (Multi-tab)

1. Откройте приложение в первой вкладке браузере (`http://localhost:5173`).
2. Разрешите доступ к камере и микрофону (при запросе браузера).
3. Введите ваше имя и `Room ID` (например, `test-room`) и нажмите **Присоединиться**.
4. Откройте вторую вкладку (или окно в режиме инкогнито), введите другое имя и тот же `Room ID` (`test-room`).
5. В обеих вкладках должно установиться P2P-видеосоединение, появится возможность переписываться в чате и управлять какамерой/микрофоном.

---

## ⚠️ Краевые случаи и их обработка

- **Отказ в доступе к медиаустройствам:** Информирование пользователя понятной ошибкой при запрете доступа к камере/микрофону.
- **Переполнение комнаты:** Сервер жестко ограничит вход, если в комнате уже 4 человека, и отправит предупреждающее сообщение `room:full`.
- **Корректный Disconnect:** При закрытии вкладки или явном выходе ресурсы `RTCPeerConnection` и медиатреки аккуратно освобождаются (`track.stop()`), а оставшимся участникам рассылается уведомление.
